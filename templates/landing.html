Bench is a browser-based data science agent. Chat about a dataset and it writes and runs real Python (Pyodide/WASM) and R (webR/WASM) against it — but that code, and the data it touches, never leave your tab. The server never sees a file, a dataframe, or a result.

What Bench actually does

Real code, not vibes

Every claim the agent makes is backed by Python or R it actually ran — visible in a tool-call trace, not summarized away.

Nothing leaves your browser

Files, parsed dataframes, and analysis state live only in the tab. The backend is a stateless relay to the model — it never receives your data.

You control what the model sees

Mask rows, columns, or individual cells. The agent still computes on the real data underneath — it just never sees the masked values.

Bring your own model

Use the hosted proxy, or point Bench at your own API key or a model running on your own machine — bypassing our backend entirely.

Asks only when it matters

When something is genuinely ambiguous and changes the result, the agent pauses and asks — instead of silently picking one interpretation.

Take the analysis with you

Export a written report with charts and the full tool trace — as a PDF, or a ZIP with re-editable chart specs.

Don't take our word for it — read the code

Every claim on this page — that your data never leaves the browser, that execution runs client-side, that masking happens before anything is sent — is a claim about code, not policy. Bench is open source under the MIT license, so none of it has to be taken on trust: read the source, verify the network calls yourself, or fork it and self-host.
